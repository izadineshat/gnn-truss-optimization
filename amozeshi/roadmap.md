## 🎯 هدف نهایی چیه؟

**در یک جمله:** به کامپیوتر یاد بدیم خودش شکل و اندازه‌ی اعضای یه خرپا رو طوری طراحی کنه که
**سبک‌ترین وزن رو داشته باشه ولی زیر بار خراب نشه.**

**در سه جمله:**
1. الان (روش سنتی) ما به کامپیوتر می‌گیم «این خرپا رو تحلیل کن» → کامپیوتر جواب می‌ده.
2. ولی اگه بخوایم بهترین طراحی رو پیدا کنیم، باید هزاران بار این کار رو تکرار کنیم → خیلی کُنده.
3. راه‌حل: یه شبکه‌ی عصبی گرافی (GNN) آموزش بدیم که **در یک لحظه** بگه «فلان طرح چقدر جواب می‌ده» بدون اینکه تحلیل کامل انجام بده.

نقشه‌ی راه زیر هم دقیقاً همین مسیر رو می‌ره: از مبانی → تحلیل → گراف → GNN → بهینه‌سازی.

## 🔹 گام ۴ — اعماق FEM: از جابجایی به نیرو و تنش

### چی یاد می‌گیری؟
الان تو جابجایی گره‌ها رو حساب می‌کنی. ولی مهندس عمران چیزهای مهم‌تری می‌خواد:

- **نیروی داخلی هر عضو:** هر میله چقدر کشیده یا فشرده می‌شه؟ (کشش = مثبت، فشار = منفی)
- **تنش (Stress):** نیرو تقسیم بر سطح مقطع → `σ = F/A`. واحدش پاسکال (Pa).
- **عکس‌العمل تکیه‌گاه‌ها:** تکیه‌گاه‌ها چقدر نیرو تحمل می‌کنن؟ (باید با بار واردشده برابر باشه — تعادل)
- **اعتبارسنجی:** جواب کامپیوتر رو با محاسبه‌ی دستی چک کن. اگه نخونی چک کنی، هیچ‌وقت مطمئن نیستی.

### چرا برای هدف نهایی مهمه؟
تو بهینه‌سازی، محدودیت اصلی‌مون **تنش**ه. یعنی: «وزن رو کم کن، ولی نذار تنش از حد مجاز رد بشه.»
پس بدون محاسبه‌ی تنش، اصلاً نمی‌تونیم بگیم یه طرح خوبه یا بد.

### فرمول کلیدی
```
جابجایی عضو:    Δ = (u_j - u_i) · (cos θ, sin θ)
نیروی داخلی:    N = (E·A / L) · Δ
تنش:            σ = N / A
```

### یه نکته‌ی طلایی
علامت تنش بهت می‌گه عضو در **کشش**ه یا **فشار**:
- `σ > 0` → کشش (مثل یه کش لاستیکی که می‌کشن)
- `σ < 0` → فشار (مثل یه ستون که روش وزن گذاشتن)

## 🔹 گام ۶ — خرپا به‌شکل گراف

### چی یاد می‌گیری؟
اینجا یه تغییر ذهنی مهم اتفاق می‌افته: **خرپا = گراف**

| در خرپا | در گراف | معنی |
|---|---|---|
| گره (Node) | Node | یه نقطه‌ی اتصال |
| عضو (Member) | Edge | یه خط بین دو نقطه |
| مختصات گره | Node feature | ویژگی‌های گره `[x, y]` |
| سطح مقطع عضو | Edge feature | ویژگی‌های یال `[A]` |
| اتصالات | `edge_index` | کی به کیه |

تو این رو توی `week1/truss_week1.py` نصفه شروع کردی. حالا کاملش می‌کنیم:

- **`edge_index`**: آرایه‌ای دو ردیفی. ستون `k` می‌گه «عضو k از گره فلان به گره بهمان».
- **ماتریس مجاورت (A)**: جدول همسایگی. `A[i][j] = 1` یعنی گره i و j به هم وصلن.
- **ماتریس درجه (D)**: هر گره چند تا همسایه داره.
- **لاپلاسین (L = D - A)**: معادل گرافیِ عملگر مشتق دوم. به GNN می‌گه «همسایه‌ها چقدر با من فرق دارن».
- **نرمال‌سازی:** چون گره‌ها درجه‌های مختلف دارن، لاپلاسین رو نرمال می‌کنیم تا شبکه پایدار بمونه.

### چرا مهمه؟
GNN روی گراف کار می‌کنه، نه روی ماتریس. بدون این گام، نمی‌تونی خرپات رو به شبکه بدی.

## 🔹 گام ۷ — GNN: پیام‌گذاری روی گراف

### چی یاد می‌گیری؟
ایده‌ی GNN در سه کلمه: **پیام، جمع، به‌روزرسانی**

تصور کن هر گره یه آدمه تو یه شبکه‌ی دوستی:
1. **پیام (Message):** هر گره به همسایه‌هاش پیام می‌فرسته: «وضعیت من اینه»
2. **جمع (Aggregate):** هر گره پیام همه‌ی همسایه‌ها رو جمع می‌کنه
3. **به‌روزرسانی (Update):** گره وضعیت خودش رو با اون پیام‌ها ترکیب می‌کنه و جدید می‌کنه

این کار رو چند لایه تکرار می‌کنی → بعد از `k` لایه، هر گره اطلاعات `k` قدم اون‌طرف‌تر رو می‌دونه.

### چرا برای خرپا معنی داره؟
دقیقاً همون اتفاقی که در خرپا می‌افته! وقتی یه گره زیر بار خم می‌شه،
این اثر از طریق اعضا به گره‌های دورتر **منتقل** می‌شه. GNN داره همین فیزیک رو یاد می‌گیره.

### انواع معماری که می‌بینی
- **GCN:** ساده‌ترین. میانگین همسایه‌ها.
- **GraphSAGE:** نمونه‌گیری از همسایه‌ها (برای گراف بزرگ).
- **GAT:** با وزن‌دهی — یعنی یاد می‌گیره کدوم همسایه مهم‌تره.
- **MPNN:** حالت کلی همه‌ی موارد بالا.

### چی پیش‌بینی می‌کنه؟
سه گزینه داری:
1. **جابجایی گره‌ها** (رگرسیون روی گره‌ها)
2. **تنش هر عضو** (رگرسیون روی یال‌ها)
3. **ماتریس سختی K** (پیش‌بینی کل ماتریس — سخت‌تر، ولی قوی‌تر)

پیشنهاد من برای شروع: **گزینه ۲**. چون تنش مستقیماً به بهینه‌سازی وصله.

## 🔹 گام ۸ — بهینه‌سازی با GNN 🎯

### چی یاد می‌گیری؟
حالا وقت برداشت میوه‌ست. دو مسیر داری:

**مسیر A — GNN به‌عنوان جانشین (Surrogate Optimization):**
```
چرخه‌ی بهینه‌سازی:
  ۱. الگوریتم یه طراحی پیشنهاد می‌ده (مثلاً: مقطع عضو ۱ = 0.003)
  ۲. GNN سریع می‌گه: «وزن = ۴۵ کیلو، حداکثر تنش = ۱۸۰ مگاپاسکال» 
  ۳. آفرینشگر بررسی می‌کنه: تنش از حد مجاز رد شده؟ → طراحی بد
  ۴. اصلاح می‌کنه و می‌ره به گام ۱
```
جای FEM کند، GNN سریع جواب می‌ده → می‌تونی میلیون‌ها طرح رو تست کنی.

**مسیر B — یادگیری تقویتی (RL):**
یه عامل (agent) که عضو به عضو جلو می‌ره و مقطع‌ها رو انتخاب می‌کنه،
و reward می‌گیره بر اساس سبکی + ایمنی طرح.

### الگوریتم‌های بهینه‌سازی که لازم داری
- **الگوریتم ژنتیک (GA):** الهام از تکامل. جمعیتی از طرح‌ها، بهترین‌ها تولیدمثل می‌کنن.
- **بهینه‌سازی ازدحام ذرات (PSO):** ذره‌ها تو فضای جواب می‌چرخن و بهترین نقطه رو پیدا می‌کنن.
- **بهینه‌سازی محدب:** اگه مسئله خطی بشه (مثلاً تو بهینه‌سازی مقطع با تنش مجاز) → جواب دقیق.
- **گرادیان‌محور:** اگه GNN قابل مشتق‌گیری باشه، می‌تونی مستقیماً گرادیان بگیری.

### معیار موفقیت
```
Minimize:  وزن کل = Σ (ρ · A_i · L_i)
Subject to:
    σ_i ≤ σ_allowable     (هیچ عضوی از حد تنش رد نشه)
    δ_max ≤ δ_allowable   (جابجایی بیش از حد نباشه)
    A_min ≤ A_i ≤ A_max   (مقطع در بازه‌ی مجاز)
```
